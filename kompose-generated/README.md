# greenbone-ce

Helm chart for the OpenVAS / Greenbone Community Edition 22.4 stack,
auto-generated from the upstream Greenbone docker-compose file with
[kompose](https://kompose.io/).

## Install

Consume the chart from GHCR (OCI):

```bash
helm pull oci://ghcr.io/<owner>/greenbone-ce --version <tag>
helm install greenbone-ce oci://ghcr.io/<owner>/greenbone-ce --version <tag>
```

This chart is generated by `.github/workflows/update-kompose-chart.yml` and
published by `.github/workflows/publish-chart.yml`. Do not hand-edit the
generated `templates/`; edit the generator or the upstream compose instead.
